# 0.3 基本词汇

在正式进入语法之前，本节先收集一些最基本、最常用的表达。它们大多是「整句记忆」的固定说法，现在不必追究其中的语法，等读完后面的章节再回过头来看，就会发现它们都符合规则。

## 问候与告别

| 德语                 | 英语                 | 中文         |
| ------------------ | ------------------ | ---------- |
| Hallo!             | Hello! / Hi!       | 你好！        |
| Guten Morgen!      | Good morning!      | 早上好！       |
| Guten Tag!         | Good day! / Hello! | 你好！（白天）    |
| Guten Abend!       | Good evening!      | 晚上好！       |
| Gute Nacht!        | Good night!        | 晚安！（睡前）    |
| Auf Wiedersehen!   | Goodbye!           | 再见！（正式）    |
| Tschüs!            | Bye!               | 再见！（非正式）   |
| Bis bald! / Bis morgen! | See you soon! / See you tomorrow! | 回头见！/ 明天见！ |

德语地区的问候语还有不少地方特色：德国南部和奥地利常说 Grüß Gott!（你好）和 Servus!（你好，再见），德国北部常说 Moin!（你好），瑞士则说 Grüezi!（你好）。

问候之后，通常会问对方近况：

- 德语：Wie geht es Ihnen? – Danke, gut. Und Ihnen?
- 英语：How are you? – Fine, thanks. And you?
- 中文：您好吗？——很好，谢谢。您呢？

对朋友则说 Wie geht's?（= Wie geht es?）和 Und dir?。Ihnen 和 dir 分别是 Sie（您）和 du（你）的与格形式，见 [1.3 代词](pronouns.md)。

## 自我介绍

| 德语                             | 英语                              | 中文            |
| ------------------------------ | ------------------------------- | ------------- |
| Ich heiße Li Ming.             | My name is Li Ming.             | 我叫李明。         |
| Mein Name ist Li Ming.         | My name is Li Ming.             | 我的名字是李明。      |
| Ich komme aus China.           | I come from China.              | 我来自中国。        |
| Ich wohne in München.          | I live in Munich.               | 我住在慕尼黑。       |
| Ich bin Programmierer.         | I am a programmer.              | 我是程序员。        |
| Ich spreche Chinesisch und Englisch. | I speak Chinese and English. | 我会说中文和英语。     |
| Ich lerne Deutsch.             | I am learning German.           | 我在学德语。        |
| Freut mich!                    | Nice to meet you!               | 很高兴认识你！       |

注意 Ich bin Programmierer 里没有冠词，德语说职业时不用冠词，这一点和中文一样，和英语不同（见 [1.1 冠词](articles.md)）。女性则要说 Ich bin Programmierer**in**（见 [0.4 构词](formation.md)）。

## 疑问词

和英语的 wh- 疑问词一样，德语的疑问词几乎都以 w 开头，所以德语里把特殊疑问句叫做 W-Fragen（W 问句）。

| 疑问词       | 例句                 | 英语                              | 询问   |
| --------- | ------------------ | ------------------------------- | ---- |
| Wie       | heißen Sie?        | What's your name?               | 属性   |
| Wie       | alt sind Sie?      | How old are you?                |      |
| Wo        | wohnen Sie?        | Where do you live?              | 地点   |
| Woher     | kommen Sie?        | Where are you from?             |      |
| Wohin     | wollen Sie?        | Where do you want to go?        |      |
| Wann      | fahren Sie?        | When do you leave?              | 时间   |
| Wie lange | bleiben Sie?       | How long are you going to stay? | 持续时间 |
| Warum     | fragen Sie?        | Why do you ask?                 | 原因   |
| Wer       | ist das?           | Who is this?                    | 人    |
| Was       | sind Sie von Beruf? | What is your occupation?       | 事物   |
| Wie viel  | Geld haben Sie?    | How much money do you have?     | 数字数量 |
| Wie viele | Personen sind Sie? | How many of you are there?      |      |

注意 wo、woher、wohin 三个词的区别：英语的 *where* 在德语里要分成「在哪里」「从哪里来」「到哪里去」三个词。这个区别在后面学介词时还会反复出现。

还要注意 wer 是「谁」，wo 才是「哪里」，会英语的人很容易把 wer 和 *where* 搞混。

## 礼貌用语

| 德语                     | 英语                         | 中文          |
| ---------------------- | -------------------------- | ----------- |
| Danke! / Danke schön!  | Thanks! / Thank you!       | 谢谢！         |
| Vielen Dank!           | Thank you very much!       | 非常感谢！       |
| Bitte! / Bitte schön!  | You're welcome!            | 不客气！        |
| Entschuldigung!        | Excuse me! / Sorry!        | 劳驾！/ 对不起！   |
| Es tut mir leid.       | I'm sorry.                 | 我很抱歉。       |
| Kein Problem.          | No problem.                | 没问题。        |

bitte 是一个万能的词，根据场合不同，可以表示：

- 请：Kommen Sie **bitte**! 请过来！
- 不客气：Danke! – **Bitte!** 谢谢！——不客气！
- 给你：**Bitte** schön, Ihr Kaffee. 给您，您的咖啡。
- 什么？请再说一遍：**Bitte?** 什么？

## 是与否：ja、nein 和 doch

德语回答一般疑问句时，用 **ja**（是）和 **nein**（不）：

- Kommst du? – **Ja.** / **Nein.**（你来吗？——来。/ 不来。）

但如果问题本身是否定的，想表示肯定的回答时，德语既不说 ja，也不说 nein，而是说 **doch**：

- Kommst du nicht? – **Doch!**（你不来吗？——不，我来！）
- Du hast keine Zeit, oder? – **Doch**, ich habe Zeit.（你没空，是吧？——不，我有空。）

英语和中文对否定问句的回答都容易产生歧义（*Yes* 到底是「是的，我不来」还是「不，我来」？），德语用一个专门的词把这个问题彻底解决了。

## 数字

| 数字 | 德语     | 数字 | 德语       | 数字   | 德语             |
| -- | ------ | -- | -------- | ---- | -------------- |
| 0  | null   | 10 | zehn     | 20   | zwanzig        |
| 1  | eins   | 11 | elf      | 21   | einundzwanzig  |
| 2  | zwei   | 12 | zwölf    | 30   | dreißig        |
| 3  | drei   | 13 | dreizehn | 40   | vierzig        |
| 4  | vier   | 14 | vierzehn | 50   | fünfzig        |
| 5  | fünf   | 15 | fünfzehn | 60   | sechzig        |
| 6  | sechs  | 16 | sechzehn | 70   | siebzig        |
| 7  | sieben | 17 | siebzehn | 80   | achtzig        |
| 8  | acht   | 18 | achtzehn | 90   | neunzig        |
| 9  | neun   | 19 | neunzehn | 100  | (ein)hundert   |

需要注意的地方：

- 16、17、60、70 会丢掉一部分字母：sech**s** → sechzehn、sechzig；sieb**en** → siebzehn、siebzig。
- 30 是 drei**ß**ig，不是 *dreizig*。
- 21 到 99 的数字是**个位在前、十位在后**，中间用 und（和）连接，这和英语童谣里的 *four-and-twenty* 是同一个思路。电话号码、价格里的数字听起来尤其容易反：

```
units = ["", "ein", "zwei", "drei", "vier", "fünf", "sechs", "sieben", "acht", "neun"]
tens  = ["", "zehn", "zwanzig", "dreißig", "vierzig", "fünfzig",
         "sechzig", "siebzig", "achtzig", "neunzig"]

def german(n):  # 21 <= n <= 99, 且 n % 10 != 0
    return units[n % 10] + "und" + tens[n // 10]

german(21)  # "ein" + "und" + "zwanzig" = "einundzwanzig"
german(57)  # "sieben" + "und" + "fünfzig" = "siebenundfünfzig"
```

- 数字写成一个词，不管有多长：345 = dreihundertfünfundvierzig，2024 = zweitausendvierundzwanzig。年份在 2000 年之前按「几十几百」读：1989 = neunzehnhundertneunundachtzig。
- 打电话时为了避免 zwei 和 drei 听混，2 常常读作 **zwo**。
- 德语的数字书写习惯和英语正好相反：千位分隔符用点，小数点用逗号。1.000,50 € 是一千欧元五十分，3,5 是三点五。程序员处理德语区的本地化（locale）时，这是一个经典的坑。

| ------------------ | ------------------ | ----------------- |
| Montag 星期一         | Januar 一月 / Juli 七月 | Frühling 春天       |
| Dienstag 星期二       | Februar 二月 / August 八月 | Sommer 夏天     |
| Mittwoch 星期三       | März 三月 / September 九月 | Herbst 秋天     |
| Donnerstag 星期四     | April 四月 / Oktober 十月 | Winter 冬天      |

## 时间

问时间：Wie spät ist es? 或者 Wie viel Uhr ist es?（几点了？）

| 时间    | 日常说法                         | 正式说法（广播、时刻表）      |
| ----- | ---------------------------- | ----------------- |
| 3:00  | Es ist drei (Uhr).           | drei Uhr          |
| 3:10  | Es ist zehn nach drei.       | drei Uhr zehn     |
| 3:15  | Es ist Viertel nach drei.    | drei Uhr fünfzehn |
| 3:30  | Es ist **halb vier**.        | drei Uhr dreißig  |
| 3:45  | Es ist Viertel vor vier.     | drei Uhr fünfundvierzig |
| 15:50 | Es ist zehn vor vier.        | fünfzehn Uhr fünfzig |

nach 是「过」，vor 是「差」，Viertel 是「一刻钟」。最需要注意的是 halb：halb vier 不是「三点半」，而是「（朝着）四点（走了一）半」，也就是 3:30。这和英语的 *half four*（英式口语里表示 4:30）正好差了一个小时。

说「在几点」用介词 um：Der Film beginnt **um** acht Uhr.（电影八点开始。）

## 总结

1. 问候语有正式和非正式之分：Guten Tag! / Auf Wiedersehen! 对 Hallo! / Tschüs!；
2. 疑问词几乎都以 w 开头，「哪里」要区分 wo、woher、wohin；
3. 对否定问句作肯定回答时用 doch；
4. 21 到 99 的数字个位在前、十位在后：einundzwanzig；
5. halb vier 是 3:30，不是 4:30。

## 练习

1. 用德语说出这些数字：21、37、99、365。
2. 用日常说法说出这些时间：7:30、9:15、11:45。
3. 填入 wo、woher 或 wohin：___ kommen Sie? / ___ wohnen Sie? / ___ fahren Sie?
4. 朋友问你 Hast du keinen Hunger?（你不饿吗？），而你其实饿了，该怎么回答？
5. 一份德国的账单上写着 1.234,50 €，一共是多少钱？

<details>
<summary>答案</summary>

1. einundzwanzig, siebenunddreißig, neunundneunzig, dreihundertfünfundsechzig。
2. halb acht, Viertel nach neun, Viertel vor zwölf。
3. Woher kommen Sie? / Wo wohnen Sie? / Wohin fahren Sie?
4. Doch! 或者 Doch, ich habe Hunger.
5. 一千二百三十四欧元五十分。德语中点是千位分隔符，逗号是小数点。
