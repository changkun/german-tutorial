# 2.4 虚拟语气

我们到目前为止学过的动词形式都属于**陈述语气**（Indikativ），用来陈述事实。而**虚拟语气**（Konjunktiv）用来表达不是事实、或者说话人不为其真实性担保的内容：转述别人的话、假设、愿望、委婉的请求。

英语里也有虚拟语气的痕迹：*If I **were** rich …*、*I wish I **had** more time*。可以看出，英语的虚拟语气借用了过去时的形式（were、had）。德语也有类似的做法，而且分得更细，有两种虚拟式：

- **第一虚拟式**（Konjunktiv I）由动词的不定式词干构成，主要用于间接引语；
- **第二虚拟式**（Konjunktiv II）由动词的过去时词干构成，主要用于假设、愿望和礼貌的请求。

中文没有虚拟语气，靠「要是……就……」「……就好了」「据说」这样的词来表达同样的意思。

## 第一虚拟式

第一虚拟式几乎只出现在书面用语中，仅仅用于表达间接引语。口语中间接引语中的动词通常与直接引语中的动词形式相同。

第一虚拟式的构成如下：

动词不定式词干，不带词尾 + -e- + 人称词尾。不加双 -e

|           | haben    | kommen    | können    |
| --------- | -------- | --------- | --------- |
| ich       | hab-e    | komm-e    | könn-e    |
| du        | hab-est  | komm-est  | könn-est  |
| er/es/sie | hab-e    | komm-e    | könn-e    |
| wir       | hab-en   | komm-en   | könn-en   |
| ihr       | hab-et   | komm-et   | könn-et   |
| sie/Sie   | hab-en   | komm-en   | könn-en   |

注意强变化动词的第一虚拟式没有元音变化：er fährt（陈述语气）→ er fahre（第一虚拟式）。

第一虚拟式形式有时和一般现在时完全相同。间接引语中如果出现这种情况，使用第二虚拟式或者 würde + 动词不定式。比如上表中 ich habe、wir haben、sie haben 和陈述语气完全一样，读者分辨不出这是在转述，所以要换成第二虚拟式 ich hätte、wir hätten、sie hätten。

系动词 sein 再次成为特例：

|           | sein        |
| --------- | ----------- |
| ich       | sei         |
| du        | sei(e)st    |
| er/es/sie | sei         |
| wir       | seien       |
| ihr       | seiet       |
| sie/Sie   | seien       |

第一虚拟式最常见于第三人称单数，因为这正是它和陈述语气区别最明显的地方（er hat → er habe，er kommt → er komme，er ist → er sei）。在新闻报道里，你会到处看到这些形式：

> Der Minister sagte, er **habe** davon nichts gewusst. Die Regierung **sei** nicht informiert worden.
>
> The minister said he had known nothing about it. The government had not been informed. 部长说，他对此毫不知情，政府没有得到通知。
>
> 解释：记者用第一虚拟式表明这是部长的说法，记者本人并不为其真实性担保。

关于间接引语，主句引导句中应包含一个「说」或「报导」类的动词，比如 sagen（说）、erzählen（讲述）、berichten（报道）、meinen（认为）。

人称代词要变化：

- 直接引语：Anna sagt: „**Ich** habe keine Zeit."（安娜说：「我没有时间。」）
- 间接引语：Anna sagt, **sie** habe keine Zeit.（安娜说，她没有时间。）

转述过去的事情，用 haben 或 sein 的第一虚拟式 + 第二分词：Er sagt, er **sei** gestern krank **gewesen**.（他说他昨天病了。）

口语中，人们通常直接用陈述语气，常常再加一个 dass：Anna hat gesagt, dass sie keine Zeit **hat**.（安娜说她没有时间。）

## 第二虚拟式

第二虚拟式既可用作替代第一虚拟式，也可用于表达一种不真实的情况、推测、猜测、愿望或礼貌的请求。

第二虚拟式可用两种方式构成：

- 规则变化动词的第二虚拟式和过去时形式相同：ich machte, ich kaufte

- 对不规则变化动词来说，过去时构成第二虚拟式的基础，加上第二虚拟式的词尾 -e，词干元音 a、o、u 变音：kam → käme，ging → ginge，gab → gäbe

不过，就算是强变化动词，尤其是在日常口语中，我们也使用 würde + 动词不定式的形式。这几乎是德语中第二虚拟式最常见的形式了。würde 本身就是 werden 的第二虚拟式，相当于英语的 *would*：Ich **würde** gern nach Japan **reisen**.（我很想去日本旅行。）

通常仅仅在助动词和情态动词的第二虚拟式中使用其独立形式，此外还有 käme、ginge、gäbe、wüsste 等少数常用动词：

|           | sein     | haben    | werden   | können    | müssen    |
| --------- | -------- | -------- | -------- | --------- | --------- |
| ich       | wäre     | hätte    | würde    | könnte    | müsste    |
| du        | wär(e)st | hättest  | würdest  | könntest  | müsstest  |
| er/es/sie | wäre     | hätte    | würde    | könnte    | müsste    |
| wir       | wären    | hätten   | würden   | könnten   | müssten   |
| ihr       | wär(e)t  | hättet   | würdet   | könntet   | müsstet   |
| sie/Sie   | wären    | hätten   | würden   | könnten   | müssten   |

dürfen → dürfte，mögen → möchte，wissen → wüsste 也有变音；sollen → sollte 和 wollen → wollte 则没有变音，和过去时完全相同。现在你应该明白了，[1.5 动词](verbs.md) 中的 möchte 其实就是 mögen 的第二虚拟式，字面意思是「我会喜欢」，所以听起来比 ich will 礼貌得多。

### 第二虚拟式的用法

- 不真实的条件，相当于英语的 *if I had …, I would …*：
  - 德语：Wenn ich Zeit **hätte**, **würde** ich mitkommen.
  - 英语：If I had time, I would come along.
  - 中文：要是我有时间，我就一起去了。
- 愿望：
  - 德语：Wenn ich doch reich **wäre**! / Ich **wäre** gern reich.
  - 英语：If only I were rich! / I'd like to be rich.
  - 中文：我要是有钱就好了！/ 我很想变得有钱。
- 礼貌的请求：
  - 德语：**Könnten** Sie mir helfen? / Ich **hätte** gern einen Kaffee.
  - 英语：Could you help me? / I'd like a coffee.
  - 中文：您能帮我一下吗？/ 我想要一杯咖啡。
- 建议：
  - 德语：An deiner Stelle **würde** ich zum Arzt gehen. / Du **solltest** mehr schlafen.
  - 英语：If I were you, I'd go to the doctor. / You should sleep more.
  - 中文：换作是我，我就去看医生。/ 你应该多睡觉。
- 推测：
  - 德语：Das **dürfte** schwierig sein.
  - 英语：That might well be difficult.
  - 中文：这恐怕会很难。
- 和 als ob（好像）连用，表示与事实不符的比较：
  - 德语：Er tut so, als ob er krank **wäre**.
  - 英语：He's acting as if he were ill.
  - 中文：他装得好像病了一样。

条件句也可以省略 wenn，把变位动词提到句首：**Hätte** ich Zeit, würde ich mitkommen.（要是我有时间，我就一起去了。）这和英语的 *Had I known …* 是同样的构造。

### 第二虚拟式完成时

第二虚拟式完成时用 sein 或 haben 的第二虚拟式 + 第二分词构成，用来表达过去没有实现的事情：

- 德语：Wenn ich Zeit **gehabt hätte**, **wäre** ich **gekommen**.
- 英语：If I had had time, I would have come.
- 中文：要是我当时有时间，我就来了。

和情态动词连用时，情态动词用不定式，放在句尾：Ich **hätte** das früher machen **sollen**.（我早该这么做的。）[0.5 词序](order.md) 中的例句 Alan hätte gestern sein Praktikum bei BMW in München anfangen sollen（Alan 本来昨天就该开始在慕尼黑宝马的实习了）用的就是这个结构。

## 总结

1. 虚拟语气用来表达不是事实、或者说话人不为其真实性担保的内容；
2. 第一虚拟式 = 不定式词干 + -e + 人称词尾，主要用于书面语的间接引语，最常见的是第三人称单数 er habe、er sei；和陈述语气相同时，改用第二虚拟式；
3. 第二虚拟式由过去时构成，强变化动词加 -e 并变音；日常口语中多用 würde + 不定式，只有 wäre、hätte、情态动词等少数动词常用独立形式；
4. 第二虚拟式用于不真实的条件、愿望、礼貌的请求、建议和推测；
5. 第二虚拟式完成时 = hätte/wäre + 第二分词，表示过去没有实现的事情。
