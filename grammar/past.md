# 2.2 过去时

德语口语中讲述过去发生的事时，基本上都是用现在完成时。有时和英语中的使用方式完全相同，但多半还是用于英语中一般过去时的概念。

书面语中，比如小说和新闻报道，则多用过去时。助动词 sein、haben 和情态动词即使在口语中，也更倾向于使用过去时。

要构成完整的过去时系列，我们还要知道的第三个时态就是过去完成时。

## 过去时

过去时有不同的构成方式，这取决于动词是规则弱变化动词，还是不规则强变化动词。

- 不规则变化动词

这类动词词干中的元音发生变化，加一般的人称词尾：

|           | kommen 来 | gehen 走  | sehen 看  | schreiben 写 |
| --------- | -------- | -------- | -------- | ----------- |
| ich       | kam      | ging     | sah      | schrieb     |
| du        | kam-st   | ging-st  | sah-st   | schrieb-st  |
| er/es/sie | kam      | ging     | sah      | schrieb     |
| wir       | kam-en   | ging-en  | sah-en   | schrieb-en  |
| ihr       | kam-t    | ging-t   | sah-t    | schrieb-t   |
| sie/Sie   | kam-en   | ging-en  | sah-en   | schrieb-en  |

- 规则变化动词

规则变化动词词干中的元音不变化。过去时通过词干后加 -(e)te- 来体现。词干以 -t、-d 结尾时，和现在时一样要加 -e-：

|           | machen 做    | arbeiten 工作     |
| --------- | ----------- | --------------- |
| ich       | mach-te     | arbeit-ete      |
| du        | mach-te-st  | arbeit-ete-st   |
| er/es/sie | mach-te     | arbeit-ete      |
| wir       | mach-te-n   | arbeit-ete-n    |
| ihr       | mach-te-t   | arbeit-ete-t    |
| sie/Sie   | mach-te-n   | arbeit-ete-n    |

过去时中，弱变化和强变化动词都加一般的人称词尾，即第一、第三人称单数无词尾，复数、第二人称单数有词尾。

- 混合变化动词

有些动词像不规则变化动词一样，词干元音发生变化，但过去时仍加规则变化动词的词尾 -(e)te-：

- bringen（带来）→ brachte
- denken（想）→ dachte
- kennen（认识）→ kannte
- nennen（称呼）→ nannte
- rennen（奔跑）→ rannte
- wissen（知道）→ wusste

> 例子：
>
> Als ich nach Hause **kam**, **schlief** mein Sohn schon.
>
> When I came home, my son was already sleeping. 我回家的时候，儿子已经睡了。
>
> 解释：kam 是 kommen 的过去时，schlief 是 schlafen 的过去时。英语的前一个动词用一般过去时，后一个用过去进行时，德语则都用过去时。

可以看出，过去时也能表达出英语中进行时的含义。

遗憾的是，不规则变化和混合变化动词的变化形式必须死记硬背，没有别的办法。

- 情态动词

情态动词的过去时和弱变化动词的过去时变化相同，不过没有了元音变音：

| 不定式   | können  | müssen  | dürfen  | wollen  | sollen  | mögen  |
| ----- | ------- | ------- | ------- | ------- | ------- | ------ |
| 过去时   | konnte  | musste  | durfte  | wollte  | sollte  | mochte |

人称词尾和 machte 相同：ich konnte, du konntest, er konnte, wir konnten, ihr konntet, sie konnten。

助动词的过去时形式完全不同：

|           | sein  | haben    | werden   |
| --------- | ----- | -------- | -------- |
| ich       | war   | hatte    | wurde    |
| du        | warst | hattest  | wurdest  |
| er/es/sie | war   | hatte    | wurde    |
| wir       | waren | hatten   | wurden   |
| ihr       | wart  | hattet   | wurdet   |
| sie/Sie   | waren | hatten   | wurden   |

日常口语中，即使其他动词都用现在完成时，这几个词也常用过去时：Ich **war** gestern im Kino.（我昨天去看电影了。）Wir **hatten** keine Zeit.（我们那时没时间。）Ich **konnte** nicht kommen.（我没能来。）还有 es gibt 的过去时 es **gab**（那时有……）和 wissen 的过去时 ich **wusste**（我那时知道），也是如此。


## 第二分词（过去分词）

我们需要第二分词来构成现在完成时，不过第二分词也用于过去完成时。

- 现在完成时：Ich **habe** gestern einen Film **gesehen**.（我昨天看了一部电影。）
- 过去完成时：Ich **hatte** den Film schon **gesehen**.（我那时已经看过这部电影了。）

第二分词的构成有很多方式，下表进行了简单汇总：

| 类型    | 第二分词的构成               | 例子                       |
| ----- | --------------------- | ------------------------ |
| 弱变化动词 | ge- + 词干 + -(e)t       | machen → gemacht         |
| 强变化动词 | ge- + 词干（元音常有变化）+ -en | schreiben → geschrieben  |
| 混合变化动词 | ge- + 变化后的词干 + -t      | bringen → gebracht       |

变化最简单的动词是以 -ieren 结尾的动词：

- studieren（上大学）→ studiert
- telefonieren（打电话）→ telefoniert
- reparieren（修理）→ repariert

变第二分词时，将不定式词尾 -en 用 -t 替代即可，并且不加 ge-。由于德语不断吸收来自其他语言的新词，这类动词的数量持续增长，这点可能会让你略感欣慰。

其他动词变化就复杂了。试着把动词想象成一个国家的居民。这里有普通公民 —— 这些是规则变化动词，他们构成居民的绝大部分。这些动词的第二分词有两个身份特征：前缀 ge- 和分词词尾 -(e)t （替代不定式词尾 -en）；动词词干部分保持不变。

当然，即使是普通市民也不全都一样。弱变化动词可分为：

- 基本动词：machen → gemacht，kaufen → gekauft，arbeiten → gearbeitet
- 带可分前缀的动词：ge- 插在前缀和词干之间。einkaufen → ein**ge**kauft，aufmachen → auf**ge**macht
- 带不可分前缀的动词：不加 ge-。besuchen → besucht，verkaufen → verkauft

每个国家都有普通公民，但也有与众不同的人，可以把它们称作特立独行的人，也就是不规则变化动词。

他们前面加 ge- 作为特征，词尾和不定式一样是 -en，不过他们中的多数词干元音会发生变化。

特立独行者也可分为：

- 基本动词：schreiben → geschrieben，sehen → gesehen，trinken → getrunken
- 带可分前缀的动词：anrufen → an**ge**rufen，aufstehen → auf**ge**standen
- 带不可分前缀的动词：verstehen → verstanden，bekommen → bekommen

下面我们还有一组类似于地下党的词，他们人数非常少，看起来与普通市民没什么两样，但内心中具有特立独行的气质，也就是所谓的混合变化动词。他们词干发生变化，但第二分词同时具有 ge- 和词尾 -(e)t：bringen → gebracht，denken → gedacht，kennen → gekannt，wissen → gewusst。

什么时候加 ge-，有一条简单的规则：**只有重音落在第一个音节上的动词，第二分词才加 ge-**。-ieren 动词的重音在 ie 上（stu**die**ren），不可分前缀从不重读（be**su**chen），所以它们都不加 ge-；可分前缀总是重读（**an**rufen），所以 ge- 插在前缀后面。重音规则见 [0.2 发音](pronounciation.md)。

> 我们必须记住不规则动词和混合变化动词，最简单的方法就是，根据他们改变词干元音的方式分组记忆，有三种可能：
>
> - A - B - A：fahren – fuhr – gefahren，kommen – kam – gekommen，lesen – las – gelesen，geben – gab – gegeben，schlafen – schlief – geschlafen，laufen – lief – gelaufen
> - A - B - B：bleiben – blieb – geblieben，schreiben – schrieb – geschrieben，stehen – stand – gestanden，fliegen – flog – geflogen，bringen – brachte – gebracht
> - A - B - C：sprechen – sprach – gesprochen，helfen – half – geholfen，trinken – trank – getrunken，finden – fand – gefunden，nehmen – nahm – genommen，gehen – ging – gegangen
>
> 这里的 A、B、C 分别指不定式、过去时和第二分词的词干元音。

> 不规则变化动词和混合变化动词必须熟记。最后将第二分词的变化总结如下：

| 动词类型       | 第二分词的构成               | 例子                         |
| ---------- | --------------------- | -------------------------- |
| -ieren 动词  | 词干 + -t，不加 ge-         | studieren → studiert       |
| 弱变化        | ge- + 词干 + -(e)t       | machen → gemacht           |
| 弱变化，可分前缀   | 前缀 + ge- + 词干 + -(e)t  | einkaufen → eingekauft     |
| 弱变化，不可分前缀  | 词干 + -(e)t，不加 ge-     | besuchen → besucht         |
| 强变化        | ge- + 词干 + -en         | schreiben → geschrieben    |
| 强变化，可分前缀   | 前缀 + ge- + 词干 + -en    | anrufen → angerufen        |
| 强变化，不可分前缀  | 词干 + -en，不加 ge-       | verstehen → verstanden     |
| 混合变化       | ge- + 变化后的词干 + -t      | bringen → gebracht         |

## 现在完成时

现在完成时通过 sein 或 haben 的现在时形式加第二分词（过去分词）构成。助动词作为变位动词位于第二位，第二分词放在句尾，构成 [0.5 词序](order.md) 中讲过的框架结构：

- 德语：Ich **habe** einen Brief **geschrieben**. / Ich **bin** nach Berlin **gefahren**.
- 英语：I wrote a letter. / I went to Berlin.
- 中文：我写了一封信。/ 我去了柏林。

可什么时候用 sein，什么时候用 haben 呢？

- 用 sein 的现在完成时

仅在很少的状况下使用 sein 。因此，最简单的方法就是，只要记住这小部分单词，剩下的就用 haben 就可以了。

下列动词在现在完成时中用 sein：

- sein（是）：Ich **bin** in Berlin **gewesen**.（我去过柏林。）
- bleiben（停留）：Wir **sind** zu Hause **geblieben**.（我们待在家里了。）
- werden（成为）：Er **ist** Arzt **geworden**.（他成了医生。）

passieren, geschehen 及具有相似含义的动词：

- Was **ist** **passiert**?（发生了什么事？）
- Das **ist** gestern **geschehen**.（这件事是昨天发生的。）

表示从 A 到 B 运动的动词：

- gehen, fahren, fliegen, kommen, laufen, reisen, umziehen 等：Wir **sind** nach Spanien **geflogen**.（我们飞去了西班牙。）

表示状态改变的动词：

- aufstehen, einschlafen, aufwachen, sterben, wachsen 等：Ich **bin** um sieben Uhr **aufgestanden**.（我七点起床了。）

- 带 haben 的现在完成时

大多数动词借助 haben 构成现在完成时，特别是反身动词、带四格宾语的动词及情态动词。

- Ich **habe** mich sehr **gefreut**.（我很高兴。）反身动词
- Sie **hat** das Buch **gelesen**.（她读了这本书。）带四格宾语
- Wir **haben** lange **geschlafen**.（我们睡了很久。）既不是位移，也不是状态改变

情态动词不常用于现在完成时，通常用过去时。如果用现在完成时，而且后面还跟着一个动词，那么情态动词不用第二分词，而用不定式，形成「双不定式」：Ich **habe** gestern arbeiten **müssen**.（我昨天不得不工作。）这种句子听起来比较笨重，所以人们更愿意说 Ich **musste** gestern arbeiten。

> 加了前缀的动词，词意有所改变，现在完成时可能加 sein，也可能是 haben。比如 Er **ist** gekommen（他来了），但 Er **hat** einen Brief bekommen（他收到了一封信）。同一个动词带宾格宾语时，也要改用 haben：Ich **bin** nach Hause gefahren（我开车回家了），但 Ich **habe** das Auto in die Garage gefahren（我把车开进了车库）。

另外，德国南部、奥地利和瑞士的人说 sitzen（坐）、stehen（站）、liegen（躺）的现在完成时，也用 sein：Ich **bin** gesessen。在德国北部则说 Ich **habe** gesessen。两种说法都是正确的。

## 过去完成时

过去完成时表示的时间是过去的过去，用于说明过去某事之前曾经发生的事。

过去完成时的构成非常简单，和现在完成时相同，只是用 sein 或 haben 的过去时形式替代现在时。

> 例子：
>
> Als wir am Bahnhof ankamen, **war** der Zug schon **abgefahren**.
>
> When we arrived at the station, the train had already left. 我们到火车站的时候，火车已经开走了。
>
> Nachdem er **gegessen hatte**, ging er spazieren.
>
> After he had eaten, he went for a walk. 他吃完饭之后去散步了。

下面是过去完成时的构成小结：

| 时态    | 构成                      | 例子                                         |
| ----- | ----------------------- | ------------------------------------------ |
| 现在完成时 | haben / sein 的现在时 + 第二分词 | Ich habe gegessen. / Ich bin gegangen.     |
| 过去完成时 | haben / sein 的过去时 + 第二分词 | Ich hatte gegessen. / Ich war gegangen.    |

## 总结

1. 口语中讲过去的事多用现在完成时，书面语多用过去时；sein、haben 和情态动词即使在口语中也常用过去时；
2. 弱变化动词的过去时加 -(e)te-，强变化动词改变词干元音，混合变化动词两者兼有；
3. 第二分词：弱变化动词为 ge-…-(e)t，强变化动词为 ge-…-en；重音不在第一个音节上的动词（-ieren 动词和带不可分前缀的动词）不加 ge-；
4. 现在完成时 = haben/sein 的现在时 + 第二分词；表示位移、状态改变的动词以及 sein、bleiben、werden、passieren 用 sein，其余用 haben；
5. 过去完成时 = haben/sein 的过去时 + 第二分词，表示过去的过去。
