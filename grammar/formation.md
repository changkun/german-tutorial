# 0.4 构词法

德语可以通过掌握构词规则来增加词汇量，这点可能是最令人兴奋的了。
所以在具体的学习德语语法之前，我们可以不妨先了解一下德语的构词法。

通过对两个或两个以上单词进行组合、或添加前缀或后缀，就能造出德语新词。
通过拆分一个很长很复杂的单词，顺序读出每一个部分，整个单词的含义就清楚了。

因此，从理论上来说，在德语里，是没有「最长」的单词的，只有「更长」的单词。

## 复合词

不管复合词（compound word，Kompositum）由多少个单词构成，总是最后一个单词作为中心词，起决定性作用。
在名词中，最后一个词决定了名词的性别。前面的单词传递给我们更多的信息，它们限定这个基本单词。

下面给出两个相同的基本词按顺序不同组成不同意思的单词：

- der Flaschenwein = die Flasche + der Wein
    + 英语: wine from a bottle (and not from a barrel)
    + 中文: 瓶子里的酒 (而不是桶里的酒)
    + 解释: 组合形式为 限定词 + 基本单词
    + 这里 Flasche 后面多了一个 -n。它和复数形式相同，但在复合词里只起连接作用（见下文），并不表示「很多瓶」
- die Weinflasche = der Wein + die Flasche
    + 英语: a bottle of wine
    + 中文: 装酒的瓶子 (而不是杯子)
    + 解释: 组合形式依然为 限定词 + 基本单词
    + 这里 Flasche 作为中心词，保持原形，整个词也跟着 die Flasche 成为阴性

注意，不能简单的理解成复合词的词义就是它各个组成部分的词义的组合，我们来看一个著名的反例：der Kindergarten = die Kinder（das Kind 的复数）+ der Garten，并不是孩子的花园，而是幼儿园。英语直接借用了这个词：*kindergarten*。

在复合词中，大多数是名词进行复合，不过其他词也有复合词。举例如下：

- 名词+名词
    + die Steuer + der Berater = der Steuerberater
    + die Liebe + der Kummer = der Liebeskummer
    + der Traum + der Job = der Traumjob
- 形容词+名词
    + rot + der Wein = der Rotwein
    + groß + die Stadt = die Großstadt
    + weich + das Ei = das Weichei（字面意思是「软鸡蛋」，口语里指胆小鬼、软蛋）
- 名词+形容词
    + das Vitamin + reich = vitaminreich
    + die Umwelt + schonend = umweltschonend
    + das Bild + schön = bildschön
    + die Medien + wirksam = medienwirksam
- 动词+名词
    + schlafen + das Zimmer = das Schlafzimmer
    + tanzen + die Schuhe = die Tanzschuhe
    + boxen + die Handschuhe = die Boxhandschuhe
- 介词+名词
    + vor +der Vertrag = der Vorvertrag
    + nach + die Sicht = die Nachsicht
    + innen（副词）+ die Politik = die Innenpolitik
- 形容词+形容词
    + dunkel + rot = dunkelrot
    + hell + blond = hellblond
- 副词+动词
    + wieder + sehen = wiedersehen（再见面），名词化后为 das Wiedersehen，即 Auf Wiedersehen 里的那个词

通常是上述几类词的混搭形式。但是理论上来说，一切皆有可能。只要在单词词尾时还记得单词以什么开始就可以了。例如：

- die Mit/fahr/gelegenheit
    + chance of a lift
    + 搭便车
- die Mit/wohn/zentrale
    + flat sharing agency
    + 合租服务中心
- der Vor/stands/vor/sitzende
    + Chairman of the Board, Chief Executive
    + 董事会主席
- die Mit/arbeiter/versammlung
    + staff meeting
    + 员工集会

> 有一个著名的的德语单词笑话，几乎在每个德语 A1 的课堂上老师都会提及，那就是下面这个词：
> 
> Donaudampfschifffahrtsgesellschaftskapitänskajütentürschloss
> 
> 英文: The lock on the cabin door of the captain from the Danube steamship company
> 中文: 多瑙河轮船航运有限公司船长舱门上的锁
>
> 可以看出，德语里复合词更像是英语中对于特定中心对象的描述性的句子，德语通过给 Schloss（锁）这个中心对象增加各种各样的词，构成了新词。
> 
> das Schloss 为中性名词，因此这个长长的单词也是中性的。


有些复合名词不能直接进行组合，需要一些连接词或字母，比如：

- die Arbeit + der Markt = der Arbeit**s**markt
- der Aufwand + die Entschädigung = die Aufwand**s**entschädigung

很多词构成复合词时用复数形式而不是单数形式，比如：

- die Aprikosen(复数) + die Marmelade = die Aprikosenmarmelade
- die Kinder(复数) + der Garten = der Kindergarten

这些夹在两个词之间的字母，叫做**连接成分**（Fugenelement）。什么时候加、加什么，并没有严格的规则，只能多见多记，但有几条经验可循：

| 连接成分    | 常见情况                                         | 例子                                                        |
| ------- | -------------------------------------------- | --------------------------------------------------------- |
| -s-     | 前一个词以 -ung, -heit, -keit, -schaft, -ion, -tät, -ling 结尾时，几乎总要加 | der Zeitung**s**artikel，der Universität**s**professor，die Liebling**s**farbe |
| -(e)n-  | 前一个词是以 -e 结尾的阴性名词，或者属于 n 变化的名词（见 [1.2 名词](nouns.md)） | die Straße**n**bahn，die Tasche**n**lampe，der Student**en**ausweis |
| -er-    | 前一个词的复数以 -er 结尾                              | das Kind**er**zimmer，das Bild**er**buch                     |
| -e-     | 少数单音节名词                                      | die Hund**e**hütte，das Tag**e**buch                          |
| 去掉 -e   | 一些以 -e 结尾的名词                                 | die Schule + das Buch = das Schulbuch，die Sprache + der Kurs = der Sprachkurs |
| 去掉 -en  | 动词作为前一部分时，只用词干                               | schlafen + das Zimmer = das Schlafzimmer，wohnen + die Gemeinschaft = die Wohngemeinschaft |

## 派生词

通过给现有的基本成分添加前缀或后缀，可以派生出新的单词，也就是派生词（derivative，Ableitung）。
这类词有很大不同，比如动词常常就需要去掉不定式词尾。

- programmieren - der Programmierer - die Programmiererin
    + to program - male programmer - female programmer
- frei + heit = die Freiheit
    + free - freedom
- fahren - die Fahrt
    + to travel - journey
- bewegen + -ung = die Bewegung
    + to move - movement
- der Sommer + -lich = sommerlich
    + summer - summery
- der Frühling + -haft = frühlingshaft
    + spring - spring-like
- be + arbeiten = bearbeiten
    + to work - to work on something

前缀常与动词一起使用，如 ankommen (to arrive)， durchlesen (to read through)，wiederholen (to repeat)。名词和形容词则常使用前缀 un- 和 in-（in- 只用于外来词），将名词变成它的否定形式或反义词，这点和英语非常类似。

- das Unglück (kein Glück)
    + calamity, misfortune (no luck)
- unglücklich (nicht glücklich usw.)
    + unhappy (not happy)
- der Unsinn
    + nonsense
- unsinnig
    + nonsensical, silly
- unfreundlich
    + unfriendly, rude
- die Inkompetenz
    + incompetence
- inkompetent
    + incompetent
- insolvent
    + insolvent, bankrupt
- die Instabilität
    + instability

后缀用于构成新的名词或形容词。也就是以其他名词、动词或形容词为基础构成新词。比如名词，后缀决定新名词的性别。

- gesund + -heit = die Gesundheit
    + healthy => health
- fröhlich + -keit = die Fröhlichkeit
    + good-humoured => good-humour
- bearbeiten + -ung = die Bearbeitung
    + to work on something => the actual work itself
- der Wunsch + -los = wunschlos
    + wish => without a wish (completely satisfied)
- leben + -haft = lebhaft
    + to live => lively
- der Wind + -ig = windig
    + wind => windy

下表列出了常见的名词后缀和它们决定的性别。遇到一个不认识的长名词时，只要看一眼它的结尾，往往就能猜对冠词，更多的规律见 [1.2 名词](nouns.md)：

| 后缀                        | 性别  | 例子                                         |
| ------------------------- | --- | ------------------------------------------ |
| -ung, -heit, -keit, -schaft | die | die Wohnung，die Freiheit，die Möglichkeit，die Freundschaft |
| -ion, -tät, -ei, -ie, -ik  | die | die Information，die Universität，die Bäckerei，die Technik |
| -in（女性）                   | die | die Lehrerin，die Ärztin                      |
| -er（做某事的人或工具）、-ling, -ismus | der | der Lehrer，der Computer，der Lehrling，der Tourismus |
| -chen, -lein（指小）            | das | das Mädchen，das Büchlein                     |
| -um, -ment                 | das | das Zentrum，das Dokument                     |

常见的形容词后缀如下，其中有好几个和英语的后缀一一对应：

| 后缀     | 含义                  | 例子                                          |
| ------ | ------------------- | ------------------------------------------- |
| -lich  | 有……性质的，每……的         | freundlich（友好的，der Freund），täglich（每天的，der Tag） |
| -ig    | 有……的，相当于英语的 -y      | windig（有风的），sonnig（晴朗的），lustig（有趣的）           |
| -isch  | 属于……的，相当于英语的 -ish/-ic | chinesisch（中国的），typisch（典型的），praktisch（实用的）    |
| -bar   | 可以被……的，相当于英语的 -able  | machbar（可行的），essbar（可以吃的），lesbar（可读的）        |
| -los   | 没有……的，相当于英语的 -less  | arbeitslos（失业的），kostenlos（免费的），hoffnungslos（没有希望的） |
| -voll  | 充满……的，相当于英语的 -ful   | hoffnungsvoll（充满希望的），liebevoll（充满爱的）          |
| -haft  | 像……一样的              | frühlingshaft（春天般的），lebhaft（活泼的）             |

## 词类转换

德语里还有一种不加任何词缀、直接改变词类的构词方式，最常见的有三种：

- **动词不定式作名词**，一律是中性，首字母大写：essen → das Essen（饭，进食），leben → das Leben（生活，生命），rauchen → das Rauchen（吸烟）。禁烟标志上写的就是 Rauchen verboten!（禁止吸烟！）
- **形容词作名词**，首字母大写，词尾仍然按形容词变化（见 [1.6 形容词](adjectives.md)）：deutsch → der Deutsche / ein Deutscher（德国人），neu → das Neue（新东西）。Was gibt's Neues?（有什么新鲜事吗？）
- **动词词干作名词**，大多是阳性，常常伴随元音变化：kaufen → der Kauf（购买），beginnen → der Beginn（开始），fliegen → der Flug（飞行，航班），springen → der Sprung（跳跃）。

## 动词前缀

动词加上前缀，可以构成意思相关、但又不太一样的新动词。同一个基本动词，常常能派生出一大家子：

- kommen（来）→ ankommen（到达），mitkommen（一起来），zurückkommen（回来），bekommen（得到）
- stehen（站）→ aufstehen（起床），verstehen（理解），bestehen（通过考试；存在），entstehen（产生）

注意 bekommen 的意思是「得到」，而不是英语的 *become*，这是一对著名的「假朋友」（false friends）。前缀分为可分前缀和不可分前缀两种，它们决定了动词在句子中的行为，见 [1.5 动词](verbs.md)。


## 总结

在这一节中，我们了解到了德语的构词法。总的来说只需要理解以下几条规则即可：

1. 长长的德语单词通常是由多个基本词组合拼接而成
2. 最后一个单词总是做中心词，而在组成的名词中，**最后一个词决定了名词的性别**
3. 两个词之间有时需要连接成分，最常见的是 -s- 和 -(e)n-
4. 派生词由增加前缀和后缀构成，一些常见的词缀有：-er/-in/-heit/-keit/-ung/-lich/-haft/-los/-ig/-bar/be-/un-/in-；名词后缀决定名词的性别
5. 动词不定式、形容词和动词词干可以直接转换成名词

## 练习

1. 拆分下面的复合词，并写出它的定冠词：Haustür、Schreibtisch、Kinderzimmer、Zeitungsartikel
2. 根据后缀判断下面名词的性：Freundschaft、Häuschen、Lehrling、Wohnung、Dokument
3. 猜猜下面形容词的意思：trinkbar、arbeitslos、sonnig、hoffnungsvoll
4. Ich bekomme einen Brief 是什么意思？

<summary>答案</summary>

1. das Haus + die Tür = **die** Haustür；schreiben + der Tisch = **der** Schreibtisch（动词只用词干）；die Kinder + das Zimmer = **das** Kinderzimmer；die Zeitung + -s- + der Artikel = **der** Zeitungsartikel。
2. die Freundschaft，das Häuschen，der Lehrling，die Wohnung，das Dokument。
3. trinkbar 可以喝的（*drinkable*），arbeitslos 失业的（*jobless*），sonnig 晴朗的（*sunny*），hoffnungsvoll 充满希望的（*hopeful*）。
