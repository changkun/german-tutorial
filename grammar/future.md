# 2.3 「将来」时

虽然使用现在时讲述将来发生的事很简单，德语中还是有特殊的将来时态。

本节标题中的「将来」之所以加了引号，是因为德语的将来时和英语的 *will* 并不完全对应。在 [2.1 现在时](present.md) 中我们已经看到，只要有一个时间词把时间交代清楚，德语就直接用现在时表达将来：Morgen **fliege** ich nach Shanghai.（我明天飞上海。）这和中文「我明天去上海」的思路完全一样，也是德语日常口语中表达将来最常见的方式。而德语的「将来时」，除了表示将来，还常常用来表达说话人的决心和猜测。

## 第一将来时

将来时用来谈论将来发生的事或者表达期望，猜测将要发生的事情。

- 将来发生的事情
  - 德语：Im Jahr 2050 **werden** mehr Menschen in Städten **leben**.
  - 英语：In 2050, more people will live in cities.
  - 中文：到 2050 年，会有更多的人住在城市里。
- 期望，包括承诺和决心
  - 德语：Ich **werde** dir **helfen**, versprochen!
  - 英语：I will help you, I promise!
  - 中文：我会帮你的，我保证！
- 猜测
  - 德语：Er ist nicht da. Er **wird** wohl krank **sein**.
  - 英语：He isn't here. He's probably ill.
  - 中文：他不在。他大概是病了吧。

注意最后一个例子：它说的根本不是将来，而是对现在的猜测，常常和 wohl（大概）、sicher（肯定）、bestimmt（一定）这些副词连用。英语的 *He will be ill* 偶尔也有这种用法，但远没有德语常见。

将来时由动词 werden 的现在时加动词不定式构成。

> werden 是变位动词，位于第二位，不定式放在句尾，构成框架结构。

|           | werden + 不定式            |
| --------- | ---------------------- |
| ich       | werde … kommen         |
| du        | wirst … kommen         |
| er/es/sie | wird … kommen          |
| wir       | werden … kommen        |
| ihr       | werdet … kommen        |
| sie/Sie   | werden … kommen        |

werden 本身的意思是「成为」，所以 Er **wird** Arzt.（他会成为医生。）里没有不定式，werden 是主要动词。两者同时出现也完全没有问题：Er **wird** Arzt **werden**.（他将会成为医生。）

> 会英语的人要再次注意：表示将来的是 werden，而不是 wollen。Ich **will** kommen 是「我想来」，Ich **werde** kommen 才是「我会来」。

## 第二将来时

第二将来时比第一将来时用得少。但遇到第二将来时时，我们必须能够辨认并理解。第二将来时用来讲述到将来某一时刻为止，已经完成的事情。

- 德语：Bis morgen **werde** ich den Bericht **geschrieben haben**.
- 英语：By tomorrow I will have written the report.
- 中文：到明天我就会把报告写完了。

也可以用第二将来时表达对过去某事的推测。

- 德语：Er ist nicht gekommen. Er **wird** den Zug **verpasst haben**.
- 英语：He didn't come. He must have missed the train.
- 中文：他没来。他大概是错过火车了。

第二将来时的构成：动词 werden 的现在时 + 过去分词（第二分词）+ haben 或 sein 的不定式。haben 和 sein 的选择和现在完成时相同（见 [2.2 过去时](past.md)）：Er **wird** schon **angekommen sein**.（他应该已经到了。）

> 德语中经常用现在完成时替代第二将来时。例如：
>
> Bis morgen **habe** ich den Bericht **geschrieben**.
>
> By tomorrow I will have written the report. 到明天我就会把报告写完了。
>
> 解释：和第一将来时一样，只要有 bis morgen 这样的时间词，德语就可以用更简单的现在完成时来代替第二将来时。

## 总结

1. 德语日常口语中表达将来，最常见的是现在时 + 时间词；
2. 第一将来时 = werden + 不定式，用来表示将来的事、承诺和决心，以及对现在的猜测；
3. 第二将来时 = werden + 第二分词 + haben/sein，用来表示到将来某时已经完成的事，以及对过去的猜测；
4. 第二将来时常常被现在完成时 + 时间词代替；
5. 表示将来的是 werden，不是 wollen。
