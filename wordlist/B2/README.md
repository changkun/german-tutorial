# 3.5 B2 词汇清单

B2 阶段的目标是能读懂报纸、专业文章，能就抽象话题进行有条理的论证。这一阶段的词汇有两个特点：一是抽象名词和书面语明显增多；二是出现了大量固定搭配，尤其是「名词 + 动词」的功能动词结构（Funktionsverbgefüge），比如 eine Entscheidung treffen（做出决定）。本清单在 [3.2 A1](../A1/README.md)、[3.3 A2](../A2/README.md) 和 [3.4 B1](../B1/README.md) 的基础上扩展，已经出现过的词不再重复，写法约定也和它们相同。

和前几个清单一样，这是本教程自己挑选的主题核心词汇，不对应某一本教材或某一份官方词表。考虑到本教程的读者，这里专门收录了一组软件开发相关的词汇。

## 功能动词结构

功能动词结构由一个名词和一个意义很虚的动词组成，整体的意思主要由名词决定，常常可以换成一个简单的动词。它们在报刊、公文和学术文章中非常常见，听起来比对应的简单动词更正式。

| 德语                                  | 相当于            | 英语                        | 中文          |
| ----------------------------------- | -------------- | ------------------------- | ----------- |
| eine Entscheidung treffen           | entscheiden    | to make a decision        | 做出决定        |
| eine Rolle spielen                  | wichtig sein   | to play a role            | 起作用         |
| zur Verfügung stehen                | verfügbar sein | to be available           | 可供使用        |
| zur Verfügung stellen               | bereitstellen  | to make available         | 提供          |
| in Frage kommen                     | möglich sein   | to be an option           | 可以考虑，有可能    |
| in Betracht ziehen                  | erwägen        | to take into consideration | 考虑         |
| Rücksicht nehmen auf + 宾格           | berücksichtigen | to show consideration for | 照顾，体谅      |
| Kritik üben an + 与格                | kritisieren    | to criticise              | 提出批评        |
| zum Ausdruck bringen                | ausdrücken     | to express                | 表达          |
| in Kauf nehmen                      | akzeptieren    | to accept (a downside)    | 甘愿承受（不利后果）  |
| Maßnahmen ergreifen                 | handeln        | to take measures          | 采取措施        |
| in Kraft treten                     | gültig werden  | to come into force        | 生效          |

用程序员的话说，功能动词结构就像是一种更啰嗦但更正式的 API：eine Entscheidung treffen 和 entscheiden 的返回值相同，只是调用方式不同。

| ----------------------------------- | ------------------------- | ----------- |
| dennoch                             | nevertheless              | 尽管如此        |
