# 3.3 A2 词汇清单

本清单按主题收集了 A2 阶段的核心词汇，在 [3.2 A1 词汇清单](../A1/README.md) 的基础上扩展，已经出现过的词不再重复。和 A1 清单一样，这是本教程自己挑选的词汇，不对应某一本教材或某一份官方词表。

写法约定和 A1 清单相同：名词给出定冠词和复数；不规则变化动词和现在完成时用 sein 的动词给出第三人称单数现在时、过去时和现在完成时；可分动词给出第三人称单数现在时。此外，本清单开始标出动词要求的介词和格，比如 warten auf + 宾格，因为这类搭配和名词的性一样，只能连同单词一起记。

## 位置动词

下面四对动词是 [1.4 介词](../../grammar/prepositions.md) 中「双向介词」的好搭档：左边是表示动作的规则变化动词，后面的双向介词接宾格（问 Wohin?）；右边是表示状态的不规则变化动词，后面的双向介词接与格（问 Wo?）。

| 动作（wohin? + 宾格）           | 状态（wo? + 与格）                                | 中文           |
| ------------------------- | -------------------------------------------- | ------------ |
| legen                     | liegen (liegt, lag, hat gelegen)             | 平放 / 平放着     |
| stellen                   | stehen (steht, stand, hat gestanden)         | 竖放 / 立着      |
| setzen                    | sitzen (sitzt, saß, hat gesessen)            | 使坐下 / 坐着     |
| hängen                    | hängen (hängt, hing, hat gehangen)           | 挂 / 挂着       |

- Ich **lege** das Buch auf **den** Tisch. → Das Buch **liegt** auf **dem** Tisch.（我把书放在桌上。→ 书在桌上。）
- Ich **stelle** die Flasche in **den** Kühlschrank. → Die Flasche **steht** im Kühlschrank.（我把瓶子放进冰箱。→ 瓶子在冰箱里。）

hängen 两种意思的不定式相同，但表示动作时是规则变化（hängte, hat gehängt），表示状态时是不规则变化（hing, hat gehangen）。

## 带介词的动词

很多动词后面要接固定的介词，介词后面的格也是固定的。这些搭配和英语、中文都对不上，只能整体记忆：

| 德语                                  | 英语                        | 中文          |
| ----------------------------------- | ------------------------- | ----------- |
| warten auf + 宾格                    | to wait for               | 等待          |
| denken an + 宾格                     | to think of               | 想到，想起       |
| sich freuen auf + 宾格               | to look forward to        | 期待（将来的事）    |
| sich freuen über + 宾格              | to be pleased about       | 为（已经发生的事）高兴 |
| sich interessieren für + 宾格        | to be interested in       | 对……感兴趣      |
| sich ärgern über + 宾格              | to be annoyed about       | 对……生气       |
| sich erinnern an + 宾格              | to remember               | 记得，回忆起      |
| sprechen über + 宾格                 | to talk about             | 谈论          |
| träumen von + 与格                   | to dream of               | 梦见，梦想       |
| Angst haben vor + 与格               | to be afraid of           | 害怕          |
| teilnehmen an + 与格 (nimmt teil, nahm teil, hat teilgenommen) | to take part in | 参加 |

问这些介词的宾语时，指物用 wo(r) + 介词，指人用介词 + 疑问代词：**Worauf** wartest du? – Auf den Bus.（你在等什么？——等公共汽车。）**Auf wen** wartest du? – Auf meinen Bruder.（你在等谁？——等我哥哥。）
