# 3.4 B1 词汇清单

到了 B1 阶段，词汇从「日常生活」扩展到「工作、社会和观点」：能谈论自己的工作经历，能对一个话题发表看法、说明理由。本清单在 [3.2 A1](../A1/README.md) 和 [3.3 A2](../A2/README.md) 的基础上扩展，已经出现过的词不再重复，写法约定也和它们相同。

和前两个清单一样，这是本教程自己挑选的主题核心词汇，不对应某一本教材或某一份官方词表。
